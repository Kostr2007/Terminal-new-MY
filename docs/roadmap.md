# Дорожная карта

## v0.1 — рабочая основа

- [x] Rust CLI `tnmy`, общая палитра существующего `myt`.
- [x] Список файлов: обычный, подробный, JSON, NUL.
- [x] Браузер: навигация, поиск, сортировка, скрытые файлы, превью.
- [x] Обёртка `nh`: явное различие rebuild/update, результат и exit code.
- [x] Fish-функции и дополнения без замены пользовательского промпта.
- [x] Nix flake, Home Manager module, CI и проверки терминала.

## v0.2 — дизайн компонентов и удобство файлов

- [x] Общие компоненты поверхностей, меток состояний и действий с эталонами.
- [x] Compact/comfortable режимы и проверка контраста на разных seed-цветах.
- [x] Асинхронная загрузка больших каталогов, отменяемые превью.
- [x] Git-метаданные с ограничением стоимости и кешированием.
- [x] Прокрутка превью, выбор пути и интеграция перехода в каталог с fish.
- [x] Темы `eza`, `bat`, `fzf` и diff через существующий генератор.

Проверено в v0.2.0: сценарий с 10 000 файлами, отмена устаревших задач,
Unicode, выбор NUL-путей и переход fish, дедлайн Git, восстановление терминала.
Git: кеш до 8 репозиториев на 2 секунды, бюджет 600 ms / 2 MiB; `r` обновляет кеш.
Блокирующий системный вызов на сетевой файловой системе может задержать
фоновую задачу, но интерфейс и выход не ждут её завершения.

## v0.3 — собственный интерфейс обновлений

- [ ] Проверка событий `nh`/Nix на локальной и CI-версиях.
- [ ] Отдельные модели evaluation/download/build/activation.
- [ ] Полный журнал, ошибки, неизвестные события и повторное подключение UI.
- [ ] Сводка изменений пакетов и поколения после успешной операции.
- [ ] Клавиатурный доступ к подробностям; корректные парольные запросы.

Готовность: успешная сборка, ошибка evaluation/build/activation, отсутствие сети,
отмена и запрос привилегий проверены. Проценты отражают известный объём;
остальные операции показывают неопределённый прогресс и реальные события.

## v0.4 — расширения Kitty и движение

- [ ] Согласованный протокол для поверхностей команд и нативных форм Kitty MY.
- [ ] Жизненный цикл карточек при скролле, resize, выделении и очистке экрана.
- [ ] Вход/выход компонентов, смена темы, reduced-motion.
- [ ] Проверка tmux, SSH и перехода на базовый текстовый режим.

Готовность: текст копируется, завершённые команды не анимируются постоянно,
нет кадров в покое, отсутствие расширений не ломает вывод.

## Выпуск 1.0

- [ ] Стабильные настройки и миграции; воспроизводимая установка/отключение.
- [ ] Проверка aarch64-linux на реальном runner.
- [ ] Замеры запуска fish и задержки prompt до/после интеграции.
- [ ] Инструкции, записи демонстраций, журнал изменений и матрица поддержки.

Новые адаптеры добавляются по частоте использования. Произвольный вывод
сторонних программ нельзя автоматически превратить в структурированные
Material-компоненты через один глобальный обработчик fish.
